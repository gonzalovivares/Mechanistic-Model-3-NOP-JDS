# mechanistic_model_3_nitrooxypropanol_jds

Code in Julia to simulate a mechanistic model of the feed additive 3-nitrooxypropanol in the rumen of dairy cattle. The code simulates an example diet with 4 dose levels of the additive, simulating the changes in methane emissions and rumen fermentation parameters. 

The description of the model is published in the Journal of Dairy Science (https://doi.org/10.3168/jds.2026-28656) 

For questions about the model or the code, please contact gonzalo.vivaresmartinez@wur.nl

Authors: Gonzalo Vivares, Jan Dijkstra and André Bannink from Wageningen University & Research
